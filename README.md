# 🎵 JavaScript Music Player

A clean, modern, and responsive web-based Music Player built using vanilla **HTML**, **CSS**, and **JavaScript**[cite: 1].

## ✨ Features
- **Audio Controls:** Play, pause, skip to the next track, or return to the previous song[cite: 1].
- **Track Details:** Displays the current song title, artist name, and real-time duration[cite: 1].
- **Interactive Seek & Volume:** Smooth progress bar to scrub through tracks and a volume slider for audio control[cite: 1].
- **Playlist & Autoplay:** Click any track in the playlist to play immediately, with an autoplay toggle to automatically advance to the next song[cite: 1].

## 🛠️ Technologies Used
- **HTML5** – Structure and layout[cite: 1]
- **CSS3** – Dark-mode styling and responsive design[cite: 1]
- **JavaScript (ES6)** – HTML5 Audio API integration and DOM manipulation[cite: 1]
